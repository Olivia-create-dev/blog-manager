# Blog Manager

## Project Description

Blog Manager is a personal mini-blog built with React and TypeScript. Users can create, read, edit and delete articles, and filter them by title, date or category. There is no backend: all articles are saved in the browser's localStorage and are kept after a page refresh.

## Technologies

- React 19
- TypeScript
- Vite
- React Router
- ESLint
- Prettier

## Installation

Node.js and npm are required.

```sh
git clone <repository-url>
cd blog-manager
npm install
```

## Run the Project

```sh
npm run dev
```

Then open the address displayed in the terminal (by default http://localhost:5173/).
